# Hospital Management System (HMS)

A complete web-based **Hospital Management System** built using **Python (Flask)** and **HTML/CSS (Bootstrap)**. This project is designed to manage hospital workflows efficiently, including patient registrations, doctor assignments, appointment scheduling, billing, and prescription management.

## 🚀 Features Included
* **Attractive Homepage & Admin Dashboard**: Clean and modern UI for administrative control.
* **Login & Authentication System**: Secure login access for administrators.
* **Patient Registration System**: Register new patients and maintain detailed medical history.
* **Doctor Management Section**: Add and manage doctors along with their specializations.
* **Appointment Booking System**: Schedule and track patient appointments with specific doctors.
* **Billing & Payment Section**: Generate and manage patient bills seamlessly.
* **Prescription Management**: Record and manage patient prescriptions and dosages.
* **Search Functionality**: Quickly search for patient records.
* **Responsive Design**: Mobile-friendly and clean interface.
